Hono: Hello World

import { Hono } from 'hono';

const app = new Hono();

// Простой endpoint
app.get('/hello', (c) => {
  return c.json({ message: 'Hello, World!' });
});

// С параметрами
app.get('/users/:id', (c) => {
  const id = c.req.param('id');
  return c.json({ userId: id });
});

// POST с телом
app.post('/users', async (c) => {
  const body = await c.req.json();
  return c.json({ created: body }, 201);
});

export default app;

Что такое Prisma ORM?

ORM = Object-Relational Mapping

Без ORM (SQL)

SELECT * FROM users
WHERE id = '123';

❌ Нет типов

❌ Хрупко

С Prisma

const user = await prisma
  .user.findUnique({
    where: { id: '123' }
  });

✅ Type-safe!

✅ Меньше ошибок

Prisma Schema: Определение модели

model User {
  id            String    @id @default(cuid())
  githubId      Int       @unique
  githubUsername String   @unique
  email         String?
  role          UserRole  @default(STUDENT)
  createdAt     DateTime  @default(now())

  sessions      Session[]  // Один ко многим
}

enum UserRole {
  STUDENT
  ADMIN
}

model Session {
  id        String  @id @default(cuid())
  userId    String
  user      User    @relation(fields: [userId], references: [id])
  createdAt DateTime @default(now())
}

  • 2️⃣ Сервер генерирует JWT
  • 3️⃣ Фронтенд сохраняет JWT
  • 4️⃣ Фронтенд отправляет в header

JWT на практике в Hono

import jwt from 'jsonwebtoken';

// Создать JWT
function createToken(userId: string) {
  return jwt.sign(
    { userId },
    process.env.JWT_SECRET!,
    { expiresIn: '7d' }
  );
}

// Проверить JWT
function verifyToken(token: string) {
  try {
    return jwt.verify(token, process.env.JWT_SECRET!);
  } catch (error) {
    return null;
  }
}

// Middleware для защиты endpoint
app.use('/api/protected/*', async (c, next) => {
  const auth = c.req.header('Authorization');
  const token = auth?.replace('Bearer ', '');

  if (!token) return c.json({ error: 'Unauthorized' }, 401);

  const payload = verifyToken(token);
  if (!payload) return c.json({ error: 'Invalid token' }, 401);

  c.set('userId', payload.userId);
  await next();
});

JWT в Hono: молодежно

Или использовать встроенный Hono JWT helper:

import { Hono } from 'hono';
import { jwt } from 'hono/jwt';

const app = new Hono();

// Middleware - защита endpoint
app.use('/api/protected/*', jwt({
  secret: process.env.JWT_SECRET!
}));

// В handler получить payload
app.get('/api/protected/me', (c) => {
  const payload = c.get('jwtPayload');
  return c.json({ userId: payload.userId });
});

// Создать токен (в обработчике логина)
app.post('/api/auth/login', async (c) => {
  const payload = { userId: user.id, role: user.role };
  const token = await Jwt.sign(
    payload,
    process.env.JWT_SECRET!
  );
  return c.json({ token });
});

Zod: Type-safe Validation

import { z } from 'zod';

// Определить schema
const CreateCategorySchema = z.object({
  name: z.string().min(1).max(100),
  slug: z.string().regex(/^[a-z0-9-]+$/),
  description: z.string().optional(),
});

// Использовать в handler
app.post('/categories', async (c) => {
  try {
    const body = await c.req.json();

    // Валидация + типизация!
    const { name, slug, description } =
      CreateCategorySchema.parse(body);

    const category = await prisma.category.create({
      data: { name, slug, description }
    });

    return c.json(category, 201);
  } catch (error) {
    return c.json({ error: 'BadRequest' }, 400);
  }
});

Правильная обработка ошибок

// Плохо ❌
app.post('/data', async (c) => {
  const data = await someFunction(); // Что если error?
  return c.json(data);
});

// Хорошо ✅
app.post('/data', async (c) => {
  try {
    const body = await c.req.json();

    // Валидация
    const validated = MySchema.parse(body);

    // Обработка
    const result = await someFunction(validated);

    return c.json(result, 200);
  } catch (error) {
    console.error(error);
    return c.json({
      error: 'BadRequest',
      message: 'Invalid data'
    }, 400);
  }
});

Частые ошибки

❌ Забыли await для async операций 
const user = prisma.user.findUnique({...}); // Ошибка!
const user = await prisma.user.findUnique({...}); // Правильно
❌ Забыли обработать ошибки валидации 
const data = schema.parse(body); // Может выбросить error!
try {
  const data = schema.parse(body);
} catch (e) {
  return c.json({ error: 'BadRequest' }, 400);
}
❌ Забыли вернуть ответ 
c.json(data); // Ошибка! Забыли return
return c.json(data); // Правильно

Performance Tips

  • Используйте select в Prisma для выбора только нужных полей
  • Индексируйте часто используемые поля (githubId, slug)
  • Кэшируйте категории (меняются редко)
  • Пагинируйте списки (не берите миллион записей)
  • Используйте connection pooling (если будет боль)
// Хорошо: берем только нужные поля
const categories = await prisma.category.findMany({
  select: { id: true, name: true, slug: true }
});

// Хорошо: пагинация
const categories = await prisma.category.findMany({
  skip: (page - 1) * limit,
  take: limit
});

Security: Базовые правила

  • Никогда не логируйте пароли и токены
  • Используйте .env для секретов (не в коде!)
  • Валидируйте ВСЕ входные данные (SQL injection!)
  • Используйте HTTPS в production
  • Проверяйте права доступа (admin vs student)
  • Ограничивайте rate limits (потом на LR11)
